# Project Proposal

Project Idea: My idea is an XR app called Found Footage. This app will be a tool to teach users about movies. This will be achieved through an exploration scene and a quiz scene. The exploration scene will present the user with a hologram of a bookcase containing DVD cases (eg 3 shelves of 5-10 dvds). The user will learn from a tutorial that they can pick up these dvds with their hands and gesture to open them. When opened, information about the specific film will be displayed in a circle around the user eg text that is scrollable with sliders, images, YouTube clips, Film OST, holograms (the baby from Eraserhead for Eraserhead). The aim is to get the user to learn by playing around at their own pace. The quiz scene will present the user with a multiple choice quiz to reienforce what they learned from the dvds. It will have a pool of questions with an appropriate amount for each film. Films will be taken from personal favourites and ones with a general consensus. I would implement a multiplayer player vs player quiz mode as a stretch goal if I have time for it.

Technology: I will make use of Godót Hands as a base to work off of. I will use Blender for models that are too complicated to create in Godot. OpenXR Vendor Tools and Godot XR Tools are essential for any XR project. I will find a suitable SFX kit in the asset store and will create bespoke SFX myself when needed. Will find a networking library in the asset store if I do implement multiplayer.
